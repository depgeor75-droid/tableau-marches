# Famille E — Croissance et dette (E1 à E5) + PIB nominal trimestriel (pour la famille F)

Testé le 22 novembre 2026. Aucune clé API nécessaire pour les sources ci-dessous (FRED : adresse `fredgraph.csv` sans clé ; passer à l'API avec clé reste possible, contenu identique).

## Constat majeur : l'API FMI DataMapper v1 est hors service

`https://www.imf.org/external/datamapper/api/v1/<INDICATEUR>/<PAYS>` : testée le 22/11/2026, réponses 404 `{"error":"Blob not found"}` (curl sans en-tête), 403 « Access Denied » (avec un User-Agent de navigateur) et 429 « Rate limit » par intermittence. Elle n'est donc pas utilisable. **Remplacement qui fonctionne : l'API SDMX 3.0 du FMI (`api.imf.org`), même jeu WEO, mêmes codes d'indicateur** (`NGDP_RPCH`, `GGXWDG_NGDP`, `GGXCNL_NGDP`, `NGDP`, `NGDPD`). Prévoir dans le robot : en-tête `Accept: application/json`, un seul appel multi-pays (séparateur `+`), reprises espacées en cas de 429.

## Appels exacts qui ont fonctionné

**FRED (sans clé)** : `GET https://fred.stlouisfed.org/graph/fredgraph.csv?id=<CODE>`. CSV à 2 colonnes (`observation_date`, `<CODE>`) ; première colonne = 1er jour de la période ; valeurs manquantes = vide ou `.` (aucune dans les séries retenues). Codes OK : `GDPC1`, `GDP`, `JPNRGDPEXP`, `JPNNGDP`, `NGDPSAXDCJPQ`, `NGDPSAXDCGBQ`, `GFDEBTN`, `GFDEGDQ188S`, `CPMNACSCAB1GQEA19`. Codes arrêtés (ne pas utiliser) : `NAEXKP01JPQ189S` (fin 2023-T3), `GBRRGDPQDSNAQ` (fin 2024-T1), `CHNGDPNQDSMEI` (fin 2023-T3), `CPMNACSCAB1GQUK` (fin 2020-T3). Introuvables (404) : `NAEXKP01GBQ189S`, `NAEXKP01CNQ189S`, `CHNGDPRQPSMEI`, `CLVMNACSCAB1GQEA20`, `NGDPRSAXDCCNQ`.

**Eurostat** : base `https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/` (JSON-stat : `value` indexé par position, périodes dans `dimension.time.category.index` ; les trimestres sans valeur sont absents).
- E1 zone euro : `namq_10_gdp?geo=EA20&unit=CLV_PCH_SM&s_adj=SCA&na_item=B1GQ&format=JSON`
- Niveau réel : `namq_10_gdp?geo=EA20&unit=CLV10_MEUR&s_adj=SCA&na_item=B1GQ&format=JSON` (1995-T1 → 2026-T3)
- PIB nominal : `namq_10_gdp?geo=EA21&unit=CP_MEUR&s_adj=SCA&na_item=B1GQ&format=JSON` (jusqu'à 2026-T2)
- Dette % PIB : `gov_10q_ggdebt?geo=BE&unit=PC_GDP&sector=S13&na_item=GD&format=JSON` (idem DE, FR, IT, EA20, EA21)
- Dette en montant : même appel avec `unit=MIO_EUR`.

**OCDE (SDMX, sans clé)** : `GET https://sdmx.oecd.org/public/rest/data/OECD.SDD.NAD,DSD_NAMAIN1@DF_QNA_EXPENDITURE_GROWTH_G20,1.1/Q..CHN+JPN+GBR+USA............?` avec l'en-tête `Accept: application/vnd.sdmx.data+csv`. La clé doit avoir exactement 13 dimensions (sinon 403 « Not enough key values »). Filtrer ensuite en local : `TRANSACTION=B1GQ`, `TRANSFORMATION=GY` (glissement annuel), `ADJUSTMENT=Y` ; colonnes utiles `REF_AREA`, `TIME_PERIOD`, `OBS_VALUE`, `OBS_STATUS`. `EA20` n'est pas dans ce flux (zone euro via Eurostat). Le flux `DF_QGDP` n'existe pas (404). Réponse volumineuse (1,5 Mo pour 4 pays, toutes transactions) : interroger un pays à la fois.

**ONS** : `GET https://www.ons.gov.uk/generator?format=csv&uri=/economy/grossdomesticproductgdp/timeseries/abmi/pn2` (idem `ybha/pn2`). CSV : 8 lignes d'en-tête (Title, CDID, Release date…), puis lignes `"1955 Q1","149440"` ; ne garder que les lignes au format `"AAAA Tn"` (le fichier contient aussi des lignes annuelles). Réponse 429 si les appels sont trop rapprochés : réessayer après 30 s.

**FMI SDMX 3.0 (sans clé)** : `GET https://api.imf.org/external/sdmx/3.0/data/dataflow/IMF.RES/WEO/%2B/USA+DEU+FRA+ITA+BEL+JPN+CHN+GBR+G163.<INDICATEUR>.A` avec `Accept: application/json` (`%2B` = dernière version, aujourd'hui 9.0.0 ; `9.0.0` explicite fonctionne aussi). Réponse SDMX-JSON : `data.dataSets[0].series["<index pays>:0:0"].observations["<index année>"][0]` ; les années sont dans `data.structures[0].dimensions.observation[0].values[].value` et **ne sont pas triées** (1992…2031 puis 1980…1991) : toujours passer par l'index. Valeurs sous forme de chaînes. `NGDP` en unités de monnaie nationale, `NGDPD` en dollars courants. Catalogue des codes : `.../structure/dataflow/IMF.RES/WEO/%2B?references=descendants`. Code zone euro : `G163` (« Euro Area (EA) ») ; `G995` ne renvoie rien. L'attribut de série `COUNTRY_UPDATE_DATE` donne la date de mise à jour par pays. Le point d'entrée SDMX 2.1 avec le code court `WEO` renvoie une erreur 500 : utiliser la forme 3.0.

## Points d'attention
- FMI : l'ancienne API DataMapper est morte ; remplacement SDMX documenté. Le FMI exige une autorisation préalable pour les téléchargements automatisés en masse et pour tout usage commercial : à trancher pour le site public (réutilisation non commerciale avec mention de la source, transformations signalées).
- Zone euro : Bulgarie dans la zone depuis 2026, donc `EA` = `EA21` ; garder une seule composition pour les ratios.
- Les PIB nominaux annualisés (US, Japon `JPNNGDP`) se moyennent ; les PIB en niveau trimestriel (zone euro, R.-U., `NGDPSAXDCJPQ`) s'additionnent.
- Dernier trimestre : 2026-T3 pour tous les g.a. (E1) ; 2026-T2 pour les dettes trimestrielles et le PIB nominal de la zone euro.
- Chine : seule source gratuite fiable trouvée = OCDE (données du NBS) ; le site du NBS bloque les robots, pas de secours.
